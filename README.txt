HOW TO ADD YOUR PHOTO
1. Pick a clear photo of yourself (portrait works best, under 1 MB).
2. Rename it to: profile.jpg
3. Put it inside the "images" folder, so the path is images/profile.jpg
4. Open index.html in your browser. Your photo replaces the "MD" letters.

If your photo is a .png, either rename the file to profile.jpg (best: export it as JPG)
or change src="images/profile.jpg" in index.html to src="images/profile.png".
File names are case-sensitive on GitHub Pages: use lowercase exactly.
